## 🔨 How to Use This Repo

### Browsing on GitHub

All `.md` files render automatically in GitHub's web interface — just click any link in the table of contents above. PDFs can be viewed directly in the browser by clicking on them.

### Cloning Locally

```bash
git clone https://github.com/amansingh2116/tech_stack.git
cd tech_stack
```

### Building LaTeX Documents

Two areas have compilable LaTeX sources — `financial_analysis/` and `remote-hire-playbook-latex/`.

**Quick build (requires MiKTeX or TeX Live):**
```bash
# Remote Hire Playbook
cd remote-hire-playbook-latex
latexmk -pdf main.tex       # Build
latexmk -c                  # Clean temp files

# Financial Analysis documents
cd financial_analysis/tex
latexmk -pdf -outdir=../pdf introduction.tex
latexmk -c -outdir=../pdf
```

Or on Windows, use the helper scripts:
```powershell
# From remote-hire-playbook-latex\
.\build.bat    # Compile PDF
.\clean.bat    # Remove auxiliary files
```

### Running Jupyter Notebooks

Notebooks (`.ipynb`) are found in `Udacity Future AWS AI Scientist/`, `algo_trading/`, and `Quant/SoQ_IITKGP/`. To run locally:

```bash
pip install jupyter
jupyter notebook
```
